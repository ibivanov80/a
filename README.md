# Буквобум

Весёлая азбука для ребёнка от четырёх лет: 33 игры, оригинальные персонажи Бум и Шмяк, сборка печатных букв, узнавание среди похожих, смешные сценки и бережная поддержка.

Все буквы доступны сразу. Нет таймера и штрафов. Герои помогают друг другу, при ошибке предлагают посмотреть вместе. В игре есть маленькое письмо от папы и приглашение придумать смешинку с близким человеком.

В разделе «Взрослым» можно выбрать 3, 5 или 10 сборок одной буквы и 5, 10 или 20 поисков среди других букв. По умолчанию: 3 сборки и 10 поисков. Каждая сборка начинается заново; между ними друг просит ещё одну букву. Появились шесть новых друзей: Лис Ложкин, Заяц Тапок, Осьминог Плюх, Робот Бип, Пингвин Пончик и Дракон Искорка.

«Слова оживают» — отдельный голосовой театр на 5 или 10 слов: прочитать или повторить слово, увидеть его по слогам, получить звёздочку и смешинку. Владелец разрешил распознавание речи ребёнка. Оно использует Web Speech API браузера; на Safari — речевой движок Apple. На некоторых устройствах обработка идёт через серверы производителя браузера. Микрофон запускается только явной кнопкой и требует разрешения браузера; его можно выключить в настройках игры. Записи и распознанный текст игра не хранит. Сохраняется только общее число звёзд. Сервис проверяет слово, а не качество произношения. При ошибках или недоступности распознавания взрослый может подтвердить услышанное слово сам.

## Запуск

Откройте [ibivanov80.github.io/a/](https://ibivanov80.github.io/a/) в Safari на iPad. Для отдельного значка: «Поделиться» → «На экран Домой». Вход в аккаунт не нужен. Наклейки и настройки сохраняются на устройстве в этом браузере.

Локально:

```sh
python3 -m http.server 4173 --directory docs
```

## Устройство проекта

- `docs/`: весь сайт, JavaScript, Canvas-сцены, SVG-персонажи, шрифты и готовые аудиофайлы.
- `docs/data.js`, `docs/letter-shapes.js`: сценарии и формы всех 33 букв.
- `docs/stories.js`, `docs/care.js`: озорные и заботливые сценки.
- `LEARNING.md`: учебное действие каждой буквы.
- `scripts/`: авторинг данных и проверки.
- `*-narration-plan.json`: тексты и актёрские ремарки. План warmth имеет приоритет над прежними версиями реплик.
- `audio-manifest.json`: тексты и технические характеристики опубликованных файлов.

Игра полностью статическая. 346 заранее записанных реплик мужским голосом Denis / ElevenLabs. Ключей и платных вызовов озвучки во время игры нет. Для обычных игр не нужны камера и микрофон; микрофон используется только в голосовом театре.

## Проверка

```sh
node scripts/check-games.mjs
node scripts/check-speech.mjs
node scripts/check-practice.mjs
node scripts/check-recognition.mjs
python3 scripts/check-audio.py
```

Первая проверка проходит все 33 сценария реальными жестами, включая ошибки выбора и обязательное узнавание перед наградой. Вторая проверяет единый канал речи и выключение звука. Аудиопроверка требует `ffmpeg` и `ffprobe` и проверяет все тексты, SHA-256 и полное декодирование AAC.

Новые проверки проходят все 33 буквы через три сборки и десять узнаваний, граничные настройки 10/20, отказ микрофона, тайм-аут, отмену и запоздалый ответ. Успешный сценарий распознавания проверяется подставным API без обращения к микрофону; он не заменяет аппаратную проверку детской речи на iPad.
